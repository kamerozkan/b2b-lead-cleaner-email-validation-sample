# Data notice

This repository contains public product examples, not a customer dataset.

- The input files mirror the three public Apify Task configurations available on 2026-07-28.
- The rows are synthetic demonstrations. They are marked with `sample_record: true`, `(sample)`, or `apify-task-demo-*` identifiers.
- The output files are based on successful public Task runs. The duplicate output has identity values redacted while preserving the decision, reason, and domain-level evidence.
- Do not interpret a sample name, role, email, phone, or LinkedIn URL as evidence about a real person.
- Do not add private customer data, credentials, API tokens, personal inboxes, or non-public enrichment data to this repository.

DNS MX evidence is domain-level evidence only. It does not prove that a specific mailbox exists, accepts mail, belongs to a named person, or will reply.

The `qualityScore` is a rule-based list-quality score. It is not a deliverability probability or sender-reputation metric.

When using the live Actor, review your lawful basis, data minimization, retention, access controls, suppression lists, and applicable privacy and marketing rules.
